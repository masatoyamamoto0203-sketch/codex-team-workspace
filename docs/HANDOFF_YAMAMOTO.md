# Codex・チーム編集 引き継ぎ
作成日: 2026-11-22（日本時間）
## 目的と現在の状態
この非公開リポジトリで、Codexとチームが変更内容をPull Requestで確認しながら共同編集する。
現在はREADMEとこの引き継ぎ資料のみ。対象となる企画名、元のコード・資料、機能要件は未確認であり、アプリ実装済みとは扱わない。以前の別リポジトリの内容は移植していない。
## Codexへの作業指示
1. READMEとこの資料を最初に読む。
2. 対象となる企画・ファイル・要件を確認する。未提供の仕様やコードを推測で補わない。
3. mainを直接変更せず、作業用ブランチで変更する。山本の初期作業ブランチはwork/yamamoto。チームの各作業は別ブランチを使う。
4. 実装に応じた動作確認を実施し、結果と未検証事項をPR本文に記載する。
5. レビュー用のPRを作成する。マージや外部公開は別途判断する。
## チームで編集する手順
所有者がSettingsのCollaboratorsから対象メンバーを招待し、メンバーが招待を承認する。現時点ではメンバーは未指定・未招待。
各自の作業ブランチで編集し、main向けにPRを作成する。変更理由・確認結果・残課題を共有し、レビュー後にマージする。
非公開リポジトリなので、URLだけでは権限のないメンバーは閲覧できない。
## 検証状況
この初期変更は文書のみ。アプリのソースコード、package.json、テスト・ビルド設定は未追加のため、npm testおよびnpm run buildは未実行。成功したとは報告しない。

- 実現したい機能と完了条件

## 接続時の注意
GitHubの接続機能からこの新規リポジトリにアクセスできない場合は、所有者が連携アプリの対象リポジトリ設定を確認する。接続確認前にCodex連携完了とは扱わない。
